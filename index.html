How it picks

Pair lift = (IPPT × 2) ÷ drum multiplier. IPPT values are from the Northview Torsion Spring Reference (11/2026). Multipliers and turns are Canimex/Action D400-96 standard-lift values (HMA 2.275″) for the selected height and track. The pick is the pair whose lift is closest to door weight.

Track matters because it changes turns on the spring, not door weight: a 15″ radius stores more turns (more high lift), 12″ fewer, low headroom fewer still. Fewer turns → less torque at the closed position → less lift from the same spring.

Low HR assumes front-mount double track on standard 4″ drums. Rear-mount or low-headroom drums use different multipliers. Cycle ratings are the chart's 15″ figures, interpolated by turns; 12″ and Low HR run fewer turns, so actual life is slightly higher.

The printed chart's 8′ column uses a 0.2500 multiplier; the D400-96 15″ value is 0.2579, so this tool shows 8′ lifts about 3% lower than the chart.
